Assessment Management System
A Full-Stack MERN Application
Project Overview
The Assessment Management System is a full-stack web application designed to simplify the creation, management, delivery and evaluation of online assessments.
The platform provides separate functionality for administrators and students. Administrators can manage assessments and questions, monitor submissions and view overall system performance. Students can browse available assessments, complete them within the allocated time and view their results.
The application uses a RESTful API to connect the React frontend with an Express and Node.js backend, while MongoDB provides persistent data storage.
Key Features
Administrator
- Secure registration and login.
- Create, view, update and delete assessments.
- Manage assessment questions and answer options.
- View student submissions.
- Monitor assessment statistics and performance through a dashboard.
Student
- Secure login and access to student features.
- Browse available assessments.
- Take assessments with a countdown timer.
- Submit completed assessments.
- View assessment results and scores.
General Features
- JWT-based authentication.
- Role-based access control.
- Password hashing.
- Responsive user interface.
- Dark and light themes.
- Automatic assessment submission when the timer expires.
- Backend validation and error handling.
